## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4 (Obsidian & Laser Crimson Theme)
- **Icons**: Lucide React + FontAwesome
- **Audio Engine**: Synthesized Web Audio API (tactile cyber frequencies, zero external audio assets)
- **Animations**: Ambient Reactive Canvas Particle Matrix + Canvas Confetti

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Roshankumarb31/sudhan_website.git

# Navigate to project
cd sudhan_website

# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
